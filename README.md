# TacSpike Slip Detection

This repository is organized by responsibility:

- `src/tacspike/`: reusable Python package code.
- `scripts/validate/`: validation and sanity-check entry points.
- `scripts/train/`: training entry points, starting from stage 2.
- `docs/plan/`: experiment plans and design documents.
- `docs/ref/`: reference papers and external materials.
- `result/`: stage-level result summaries and lightweight validation artifacts.

Large datasets, logs, plots, and checkpoints should stay outside Git.
